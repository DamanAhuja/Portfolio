Eight pieces. The stage follows the one you pick.

Smart Buggy

The driver tablet and passenger kiosk are Kotlin and Jetpack Compose. The tablet publishes indoor position, battery, and seats over MQTT every second, and walks the trip through the Node.js engine. A buggy with a stale heartbeat, a low battery, or a charging state drops out of the pool. Riders headed to the same pier share a vehicle, up to five seats, before an idle buggy is called.

I also built an ARCore proof of concept that checked the airport’s vendor-led AR wayfinding flow before rollout.

Kotlin · Jetpack Compose · Node.js · MQTT · PostgreSQL · ARCore · Situm

Carbon

Carbon is an AI business OS for smaller companies. I researched how Salesforce and Mailchimp model users, core objects, OAuth, and rate limits, and wrote that up across three pull requests. The slice in progress copies Mailchimp audiences into Carbon contacts and has to survive expired tokens, rate limits, and partial syncs.

OAuth · REST · Salesforce · Mailchimp · Node.js

XRchitect

A collaborative VR interior design app. Several people edit the same room, and Photon keeps that shared state in sync. It is on the Meta Store, used for both client walkthroughs and learning.

Meta XR SDK · Photon · Unity

View on the Meta Store

Combat-XR

A tactical VR trainer that turns defence drills into scenarios a team can rerun. AI handles scenario management. The interaction layer is Unity’s XR Interaction Toolkit.

Unity · XR Interaction Toolkit

TeleTwin

A live twin of telecom tower assets. A YOLO pipeline watches the scene and a PostgreSQL stream keeps the operational record, so a remote team can inspect without a site visit.

Python · YOLO · PostgreSQL

AR indoor navigation

Marker-based wayfinding in the browser. The path is drawn over the physical room with WebXR, so a first-time visitor does not install an app. Separate from the airport proof of concept, which used ARCore on device.

WebXR · SVG · JavaScript · ARCore

TopologyXR

A data-center planning space built from scanned infrastructure. Layout generation is AI-assisted, and the assets are detailed enough to review a room in a headset.

VR / MR · photogrammetry · AI-assisted layout

View on the Meta Store

TeleAttendance

An attendance pipeline with a Telegram bot in front, a REST API in the middle, and a database behind it. The manual entry step is gone. Logging and lookup happen as the messages come in.

Node.js · Telegram Bot API · REST · SQL
